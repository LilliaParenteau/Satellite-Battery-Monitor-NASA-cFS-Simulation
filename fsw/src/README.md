# cFS Satellite Battery Monitor

A C++ application that simulates satellite battery monitoring using NASA's Core Flight System (cFS).

## About

I made this project to practice C++ and learn how to work with NASA's cFS framework. The program simulates a satellite battery losing charge and checks when the battery gets too low.

I also used this project to get more experience working with CMake, Linux, and setting up VS Code for building and running applications.

## Features

- Simulates a battery decreasing from 100% to 10%
- Checks the battery level every second
- Sends warnings when the battery reaches 20% or below
- Uses cFS Event Services to display battery levels and warnings
- Includes a separate C++ program to test the battery simulation
- Includes VS Code tasks for building, running, and testing

## Technologies

- C++
- NASA Core Flight System (cFS)
- CMake
- GCC/G++
- Linux (Ubuntu/WSL)
- Visual Studio Code

## Setup and Running

This project requires NASA cFS and a C++ compiler.

1. Download and set up [NASA cFS](https://github.com/nasa/cFS).
2. Add the `battery_monitor` folder to `cFS/apps`.
3. Open `sample_defs/targets.cmake` and add `battery_monitor` to the application list.
4. Open `sample_defs/generate_startup.cmake` and add the battery monitor startup entry using `BATMON_Main`.
5. Enable C++ in the build settings. In `sample_defs/arch_build_custom.cmake`, change `-std=c99` to `$<$<COMPILE_LANGUAGE:C>:-std=c99>` so it only applies to C files.
6. From the main cFS folder, run `make native_std.prep` and then `make native_std.install`.
7. Go to `build-native_std/exe/cpu1` and run `./core-cpu1`.

The startup entry used for the application is:

`CFE_APP, battery_monitor, BATMON_Main, BATTERY_MONITOR, 85, 16384, 0x0, 0;`

This entry goes in the startup configuration generated by `generate_startup.cmake`.

Once cFS starts, the program displays the battery levels and low-battery warnings.

I also added VS Code tasks so I can build and run the program without typing the same terminal commands every time.

## Testing

I included a separate C++ program to test the battery simulation without running the full cFS framework.

To run it in VS Code:

1. Open the `battery_monitor` folder.
2. Go to **Terminal > Run Task**.
3. Select **Test Battery**.

The program should display battery levels from 100% to 10%, with warnings at 20% and 10%.

To test it with NASA cFS, select **Run cFS** and check the output for the battery messages.

## Notes

- The battery levels are simulated, not taken from a real satellite.
- NASA cFS needs to be installed separately.
- Some cFS setup changes are made outside this project folder, so they aren't included in this repository.
- The VS Code tasks are set up for this project to be inside the cFS folder.
